# snte_sourceban
complete file of all users who tried to exploit on garrysmod servers hosted at mtxserv.com (2018/2019?)

initially mTxServ team had set up a website with databases related to garrysmod game servers, Seb one of the cofounder of mTxServ had set up a page dedicated to all SNTE bans registered on all servers equipped with the addon.

Unfortunately the site has closed for lack of investment, however i managed to catch the json format the entire list of people banned on mtxserv.com machines, it is now time to gift it publicly.

Maybe an operation like this will happen again or maybe not, only the future will tell us. If you have tried to cheat on gmod servers before 7 years of SNTE existence try to find your steamid in this massive list..its funny nostalgia
